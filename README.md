Self Assessment 

1.	Discuss how completing your coursework throughout the program and developing the ePortfolio has helped you showcase your strengths, shape your professional goals and values, and prepare to enter or become more employable in the computer science field.

Developing my portfolio throughout this program has helped serve as a refresher for many programming languages and techniques. For example, refining classes for the CS320 project has given me more practice on using Java to make object-oriented code where a constructor is used with necessary parameters that utilize setter and getter methods for encapsulation. I went a step further refining this class by creating a variable within the constructor to equal a date that is one year ahead of the current date. I then used this “maxDate” to add extra validation within the constructor for the appointment date parameter, so if a user tries to create a date more than a year ahead of time an exception would be thrown, just like how an exception is set to be thrown if a user tries to pick a date before the current date. 
Throughout my SNHU computer science courses I have used many programming languages to prepare me to work as a development team member for various jobs. These languages include Python used in CS340, C++ used in CS 210 and CS330, Java used in CS320, JavaScript in CS465. For working on databases I have used SQL and NoSQL in courses like DAD 220, which is where I worked on database creation, management and SQL querying.
In the course CS250 Software Development Lifecycle I learned important lessons on communicating and working with stakeholders. More specifically, how the Agile/Scrum framework will have the Product Owner will discuss the necessary requirements with the stakeholder. Then the Scrum Master will organize regular events to keep everyone on track with the stakeholder’s requirements, while also giving each developer a chance to give their feedback.
CS300 helped me work with data structures and algorithms by teaching me how to use C++ to store, organize, and manipulate data. To help keep these systems secure, I had the course CS305 Software Security that went over creating checksums for data verification, adding secure communication mechanisms, using dependency checks to find various vulnerabilities, and suppressing false positives to isolate the important vulnerabilities to patch. 

2.	Summarize and introduce how your artifacts fit together and inform the portfolio as a whole.

The artifacts I have included focus on the categories Software Engineering and Design of perfecting object-oriented programs in CS320, Algorithms and Data Structures with protecting data integrity by avoiding buffer overflow crashes and endless recursion in CS405, and the Databases category by perfecting methods to create, read, update, and delete information from the database. In other words, how data is manipulated efficiently in memory as the program runs. Databases serve as the permanent storage layer for the system to access information from and store new data. I included these so hiring managers and recruiters can see I have studied for various roles of the software development process. It shows how I would work better with a team by understanding the different jobs that go into developing the system. As well as showing I would have flexibility to work on different roles that are needed.
